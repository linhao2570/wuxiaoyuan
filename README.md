# aiqin - 广东校园助手

一个超轻量的 Android 应用，专门用来辅助「广东校园」客户端保持校园网在线。

## 设计理念

**便捷实用、最少干扰。**

亮屏时：你用你的手机，我们完全不打扰。
熄屏时：悄悄重置一次广东校园，保持网络在线。

## 功能

- 一键开启后台监测
- 亮屏时不干扰，只做最基础的网络检查
- 首次检测到断网时，快速拉起广东校园后立刻返回当前应用
- 熄屏 30 秒后自动重置广东校园（关闭 + 重启）
- 每 40 分钟自动重置一次（仅在持续熄屏状态下）
- 用户亮屏后，重置计时器立刻归零，等待下一次熄屏
- 无障碍服务辅助点击登录/重试按钮（可选，不开启也能用基础功能）

## 工作流程

```
用户开启后台监测
  |
  +-- 初始检查：断网了吗？
  |     |
  |     +-- 没断 -> 什么都不做，等待
  |     +-- 断了 -> 快速拉起广东校园 -> 立刻返回当前应用 -> 等它自己连
  |
  +-- 亮屏时
  |     |
  |     +-- 不做任何主动操作（最少干扰）
  |     +-- 只在网络状态变化时做基础检查
  |
  +-- 熄屏时
        |
        +-- 熄屏 30 秒 -> 重置广东校园（关+开）
        |
        +-- 每 40 分钟重置一次（仅持续熄屏时）
        |
        +-- 用户亮屏 -> 计时器归零，停止熄屏逻辑
```

## 使用步骤

1. 安装并打开 aiqin
2. 点击「开启后台监测」
3. （可选）点击「开启无障碍权限」，在系统设置中找到 aiqin 并开启
   - 开启无障碍后，广东校园卡在登录/重试页面时会自动点击
   - 不开无障碍也能用，只是可能偶尔登录不上
4. 给 aiqin 开启以下权限（必须做，否则后台会被杀）：
   - 自启动
   - 后台活动
   - 电池优化设为「不限制」
   - 通知权限（前台服务需要）

## 重要说明

- **亮屏时不会自动跳转广东校园**（除非刚开启时检测到断网的那一次快速拉起）
- **所有重置操作都在熄屏时进行**，不影响你正常使用手机
- 熄屏重置后，广东校园在后台运行，亮屏时你看到的还是你之前在用的 App
- 本应用不会上传任何账号密码，也不会记录个人信息
- 仅限个人自用，请遵守校园网使用规定

## 项目结构

```
lib/main.dart                          - Flutter UI
android_custom/                        - Android 原生自定义代码
  app/src/main/AndroidManifest.xml     - 清单文件
  app/src/main/java/com/wyu/esurfing/
    MainActivity.java                  - 主 Activity + MethodChannel
    MonitorService.java                - 前台监测服务（核心调度）
    ClientAccessibilityService.java    - 无障碍服务（辅助点击）
  app/src/main/res/xml/
    accessibility_service_config.xml   - 无障碍服务配置
.github/workflows/build.yml            - GitHub Actions 构建配置
```

## 构建

通过 GitHub Actions 云端构建，推送代码到 main 分支后，在 Actions 页面下载 `app-debug.apk`。
