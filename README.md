# aiqin - 广东校园助手

一个轻量的 Android 应用，专门用来辅助「广东校园」客户端自动登录校园网。

## 功能

- 启动即自动开启后台监测
- 前台服务常驻，降低被系统回收概率
- 自动判断广东校园是否在运行，未运行则自动拉起
- 网络断开时自动通过无障碍服务点击登录按钮
- 定时"重置"策略：定期关闭并重启广东校园，利用其启动时自动连接的特性保活
- 三态识别：点我登录 / 重新检测 / 已连接（断开网络）

## 工作流程

```
aiqin 启动
  |
  +-- 启动前台监测服务
  |
  +-- 第一阶段（前 1 分钟）：每 5 秒检测一次
  |     |
  |     +-- 网络正常 -> 什么都不做
  |     +-- 网络异常 -> 执行重连流程
  |
  +-- 第二阶段（1 分钟后）：每 5 分钟重置一次（测试期）
  |     |
  |     +-- 关闭广东校园 -> 重新拉起 -> 等待自动连接 -> 返回桌面
  |
  +-- 网络回调：WiFi 断开时立刻触发重连，不用等轮询
```

### 重连流程

```
检测到网络异常
  |
  +-- 广东校园在运行吗？
  |     |
  |     +-- 未运行 -> 启动广东校园 -> 等自动连接 / 无障碍辅助
  |     +-- 已运行 -> 无障碍检测按钮状态
  |           |
  |           +-- "点我登录" -> 点击
  |           +-- "重新检测" -> 点击
  |           +-- "断开网络" -> 已连接，返回桌面
  |
  +-- 点击/启动后约 4 秒，自动返回桌面
```

## 使用步骤

1. 安装并打开 aiqin（默认自动开启监测）
2. 点击「开启无障碍权限」，在系统设置中找到 aiqin 并开启
3. 给 aiqin 开启以下权限（必须做，否则后台会被杀）：
   - 自启动
   - 后台活动 / 后台弹出界面
   - 电池优化设为「不限制」
   - 通知权限（前台服务需要）

## 关于"静默"的说明

**无法做到完全后台静默地操作另一个 App**，原因是 Android 系统的安全限制：

- 启动另一个 App：可以从后台发起，但目标 App 启动后通常会自己跳到前台
- 无障碍点击按钮：必须等目标 App 的界面可见才能读取和点击
- 我们能做的：启动后等它自动连，连完立刻自动返回桌面，尽量减少前台时间

这是系统规则，不是代码能绕过的。

## 重置策略说明

为什么要做"关闭+重启"而不是直接点按钮？

- 广东校园每次启动基本上会自动连接
- 有时候卡在"正在连接"状态，点按钮也没用，重启反而更稳
- 相当于一个定期保活机制

测试期设为 5 分钟一次，确认稳定后可以改成 90 分钟。

## 重要限制

1. 按钮文字匹配基于当前版本的广东校园客户端，如果版本更新后按钮文字变了需要调整
2. 无法完全静默操作另一个 App，目标 App 会短暂出现在前台
3. 仅限个人自用，请遵守校园网使用规定
4. 不会绕过任何认证，所有操作等价于手动点击官方客户端

## 项目结构

```
lib/main.dart                          - Flutter UI
android_custom/                        - Android 原生自定义代码
  app/src/main/AndroidManifest.xml     - 清单文件
  app/src/main/kotlin/com/wyu/esurfing/
    MainActivity.kt                    - 主 Activity + MethodChannel
    MonitorService.kt                  - 前台监测服务（核心调度）
    ClientAccessibilityService.kt      - 无障碍服务（点击按钮）
  app/src/main/res/xml/
    accessibility_service_config.xml   - 无障碍服务配置
.github/workflows/build.yml            - GitHub Actions 构建配置
```

## 构建

通过 GitHub Actions 云端构建，推送代码到 main 分支后，在 Actions 页面下载 `app-debug.apk`。
